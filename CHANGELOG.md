# Changelog

All notable changes to carve-wysiwyg are documented in this file.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [Unreleased]

Nothing released yet. The initial capability set:

### Added

- Rich structure palette, attribute inspector, lint navigation, source diff,
  searchable cross-reference targets, and structured starter document.
- Collapsible document-metadata editing for common frontmatter fields, with a
  raw YAML/TOML escape hatch and a toolbar shortcut to the card.
- Semantic Visual/Source tab activation, clearer edit-mode tables, accessible
  dark-theme links, exact-source fallback editors, document-aware reference
  pickers, and editable abbreviation/link-definition cards.
- A distinct fenced **Code block** action with language/source fields and safe
  fence widening, separate from inline code and multi-block code groups.
- Code languages use a right-aligned editor footer and a zero-layout-cost preview
  hover overlay with an accessible copy action. Preview code is syntax-highlighted,
  including Carve through the bundled `carve-grammars` highlight.js definition.
- KaTeX renders inline and display math in preview, with both forms available from
  the structure palette. Task lists, blockquotes, and inherited table alignment
  now match the rendered surface more closely while editing.
- Carve's extension presets are registered for both import and preview; Mermaid
  is rendered lazily in-browser and included in the starter document, while
  diagram source blocks remain separate from ordinary code controls.
- Canonical `carve-grammars` editor chrome and `carve-css` preview styles, with
  working tab switching in both the editor and rendered preview.
- Prominent live-demo link and focused user README; development, dependency,
  deployment, and round-trip details now live under `docs/`.
- A static, hosted WYSIWYG editor for Carve with three live panes: a Tiptap
  editor built on carve-grammars' `CarveKit`, a read-only Carve source pane
  regenerated by `serializeToCarve` on every edit, and an HTML preview rendered
  by carve-js.
- Toolbar wired to Tiptap commands with Carve's visual semantics: bold, italic,
  underline, strike, inline code, H1/H2, bullet and ordered list, blockquote,
  link.
- Carve -> editor round trip through `carveToProseMirror` via the import box and
  the "Load Carve" button.
- `npm run check:pins` (and the `engine-drift` workflow) enforce that the
  carve-grammars dependency is a commit pin on `main`, that the lockfile
  resolves to the commit `package.json` names, and that the pinned grammar is
  not older than the spec revision the installed engine was built against.
